# Standby Pro 1.1.0-preview.2

24 October 2026 · app 1.1.0+3 · source and browser preview, with native compilation evidence.

This packaging update includes the full app MIT notice in the bundle and existing open-source licences screen. Roboto's notice remains registered. It also adds focused keyboard, semantics, reduced-motion, large-text, platform-channel and licence regressions, plus pinned Flutter source/native CI. Existing display, timer, weather, preferences and package identities are retained. The historical baseline and earlier release assets are preserved.

The recorded toolchain is Flutter 3.41.9/Dart 3.11.5. Full source CI passes 44 tests, clean analysis and web release compilation. Initial unchanged native projects compiled as an Android debug APK and iOS simulator app; [the dated evidence](https://github.com/Ghostzy0/standby-pro/blob/master/docs/evidence/native-hosted-builds-2026-10-24.md) records their exact source/toolchains and disposable-artifact limitation. A separate local arm64/minimum-iOS15 SPM experiment uses modified project configuration and ad-hoc signing, with no developer/store identity. It is not an unchanged universal/iOS13 artifact.

Final native reruns at release source `1a21922f5d49790257c01e2106104f4acdd155f3` also passed analysis and all 44 tests each: [Android debug compilation](https://github.com/Ghostzy0/standby-pro/actions/runs/40120081277) and [iOS simulator compilation](https://github.com/Ghostzy0/standby-pro/actions/runs/40120575397). The disposable Android APK reported SHA-256 `f41058a82c82b376a3efb156ae15cce2d13907de005634be5e8f8dc0aa5ca68b`; neither native output was retained or installed. This hash cannot recover the APK. No iOS bundle hash was recorded.

No APK/IPA is distributed by this release. A build/checksum is not physical-device or signing acceptance. Phone behavior, TalkBack/VoiceOver, install/update continuity, lock/unplug/background behavior and long-run battery/thermal/OLED remain in [issue4](https://github.com/Ghostzy0/standby-pro/issues/4). Weather's service rights and untested missing-glyph browser font fallback remain as documented for preview.1.

Build the recorded source using Flutter 3.41.9:

```sh
git clone https://github.com/Ghostzy0/standby-pro.git
cd standby-pro
git checkout v1.1.0-preview.2
cd app
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter build web --release --base-href /standby-pro/demo/ --no-web-resources-cdn
```

Keep that web base path when serving, or rebuild with `--base-href /` for a local root. Native builds need the platform prerequisites and an explicitly controlled identity for phone installation. Compare downloadable source/web archives with the release SHA256 manifest; do not reuse a disposable CI debug checksum as a download manifest.
