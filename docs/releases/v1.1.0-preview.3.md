# Standby Pro 1.1.0-preview.3

25 October 2026 · app1.1.0+4 · source and browser preview.

A paused focus timer retained its time but still said Ready when you are and offered Start focus. It now shows **Paused** and **Resume focus**. Reset, choosing a fresh duration and completion keep distinct states. Timer cadence, foreground-only scope, package identities and historical releases are preserved.

The existing injected-clock regression now checks pause hold, resumed countdown, reset, duration selection and completion. The total stays44 tests. Source CI passes all44 tests, clean analysis and web compilation. A clean compiled Chrome run at390×844 verifies the new pause/resume/reset feedback, no page errors and origin-only requests while weather is off. The supplied archive metadata records the exact source and file counts.

The issue was observed in an actual privately restored experimental SPM simulator bundle (build3, arm64/minimum-iOS15/ad-hoc). Fixed build4 compiled and was independently hash/mode-restored; its remaining native workflows are tracked separately. This source/web release is not a physical-phone, production-signing, VoiceOver/TalkBack or long-run power/display acceptance. No public APK/IPA is supplied. Earlier Android/default CocoaPods compilation evidence belongs to preview.2 source and is not relabelled as a new build.
